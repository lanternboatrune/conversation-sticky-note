# conversation-sticky-note（对话便签）

在每个对话的右下角放一张微软便签样式的便签，内容按对话独立保存。支持加粗、列表等基础排版，适合记临时要点、待办和参考链接。

## 功能

- **按对话隔离**：每个 `sessionId` 一份内容，切到别的对话不会串。
- **富文本**：加粗、斜体、下划线、删除线、无序列表，底部工具条会高亮光标处生效的格式。
- **可折叠**：便签可收起成一个小角标，不挡住阅读区。
- **可调整大小**：左上角有拖拽手柄，向左上拖即可放大，范围 200–640 px；每个对话各记一份尺寸，右下角位置不动。
- **深色模式**：跟随 DSH 主题自动切换，五种便签颜色各有一套深底色板。
- **中英双语**：跟随界面语言。

## 使用

打开任意对话，右下角会出现便签。点开直接编辑，内容自动保存；再次点击可折叠。拖动左上角斜纹手柄可调整这张便签的大小，尺寸按对话各自记住。便签只存在本机浏览器，不进会话记录，也不会上传。

## 数据存储

| 键 | 位置 | 内容 |
|---|---|---|
| `dsh.conversation-sticky-note.v1.<sessionId>` | `localStorage` | `{ v, html, tone, open, w, h }` |

清除浏览器站点数据会一并清除便签；卸载插件不会删除已有记录。

## 插槽

| 插槽 | id | order | 作用 |
|---|---|---|---|
| `shell.overlay` | `conversation-sticky-note` | 20 | 便签本体 |
| `conversation.composer.dock` | `conversation-sticky-note-bridge` | 102 | 探测当前 `sessionId` |

## 安装

```powershell
dsh plugin add link:<本目录绝对路径>
```

或在本机 DSH 的插件管理里以 `link:` 方式注册。客户端插件，改完刷新页面即可生效。
